# Общая граница доступа Mantis MCP

28 сентября 2026 года в grill пользователь подтвердил: допущенные к Mantis MCP сотрудники образуют одну доверенную группу и могут видеть всё, что доступно служебному аккаунту, включая приватные обращения и комментарии. Выбрана общая граница доступа вместо фильтрации по личным аккаунтам сотрудников; это позволяет использовать единый индекс без сопоставления персональных прав, но подключение нового пользователя к MCP тем самым предоставляет ему весь этот общий доступ. Переход к персональной видимости потребует пересмотра модели доступа и выдачи; решение не предоставляет служебному аккаунту дополнительных прав и не разрешает реальные записи в Mantis.

Чтобы общий аккаунт не скрывал человеческого инициатора, пользователь выбрал обязательное имя или логин из клиентского профиля: журнал всех операций и компактную подпись в создаваемых и редактируемых текстах. Изменение только полей не добавляет отдельного комментария. Такая подпись является заявлением клиента внутри доверенной группы, а не аутентификацией под личным аккаунтом Mantis; операцию выполняет служебный аккаунт, а автор исходного чужого комментария не подменяется.
