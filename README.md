# 1C Agent Workflow

Workflow для разработки конфигураций и расширений 1С с помощью AI-агента.

## Быстрый старт

Для обычной инициализации из стабильного канала `master` откройте папку будущего проекта в поддерживаемом AI-клиенте и напишите:

```text
Инициализируй 1С-проект по файлу https://raw.githubusercontent.com/xmentosx/1c-agent-workflow/master/AGENT-INSTALL.md
```

Для проверки текущего канала разработки `develop` используйте отдельную команду:

```text
Инициализируй 1С-проект по файлу https://raw.githubusercontent.com/xmentosx/1c-agent-workflow/develop/AGENT-INSTALL.md
```

## Что делает workflow

- инициализирует Git-проект из исходной информационной базы;
- хранит выгрузку основной конфигурации в `master`;
- создает изолированные ветки разработки конфигураций и расширений;
- копирует активную ветку вместе с точным состоянием базы, логами и verification evidence для параллельной работы;
- обновляет копию базы измененными файлами и проверяет результат через Vanessa Automation;
- обновляет ветку свежим состоянием исходной базы;
- выгружает проверенный результат в `CF` или `CFE` для ручного переноса.

## Поддерживаемые клиенты

Поддерживаются Codex, Kilo Code, Claude Code, Cursor, OpenCode, Kimi Code, Qwen Code, Command Code, Cline и Pi. При инициализации выбирается ровно один активный клиент. Позже выбор можно изменить из чистой ветки `master` через `/itl-switch-client <client>`; созданные ветки разработки обновляются отдельно.
