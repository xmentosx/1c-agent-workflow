## Why

Аналитику нужно находить готовые решения по описаниям, комментариям и именам вложений во всей доступной базе Mantis, затем по конкретной команде создавать и изменять обращения. Сейчас Mantis MCP предоставляет только `read_ticket`, `get_attachment` и `health`; поиск и запись отсутствуют, а изменение установленного Mantis пользователем исключено.

## What Changes

- Добавить точный, текстовый и семантический поиск с фильтрами, группировкой по обращениям и ссылками на конкретные совпадения. По умолчанию охватывать все доступные служебному аккаунту проекты и статусы, включая закрытые обращения и доступные приватные данные. Индексировать имена вложений, включая вложения комментариев; содержимое файлов и OCR в индекс не включать.
- Вести отдельное состояние Mantis в SQLite + Zvec. Инкрементально опрашивать проекты по **дате изменения** обращения (`updated_at` / `last_updated`), с целью обычного обновления до пяти минут при исправных зависимостях. Дата создания не является основанием контрольной точки. Новый проект загружать отдельно; неизменённые фрагменты повторно не эмбеддировать.
- Проверять найденные и открываемые обращения при доступном Mantis. При сбое продолжать выдачу из кэша без предельного срока; подтверждённый отзыв доступа или удаление очищает локальный текст, векторы и файлы. Для изменений, не сдвигающих дату обращения, принять ограниченную обнаружимость без регулярного полного обхода.
- Добавить ограниченную запись через API существующего MantisBT 2.28.1: создание и изменение поддерживаемых полей обращений, своих и чужих комментариев, загрузку файлов. Проверять фактические права и результат, останавливать известные конфликты; сохранить явно принятый остаточный риск гонки с другими клиентами.
- Считать конкретную команду разрешением на запись без обязательного повторного подтверждения. Фиксировать инициатора из профиля клиента в журнале и подписывать создаваемые/редактируемые тексты. Составные операции продолжают только незавершённые шаги; неоднозначный результат создания запрещает автоматический повтор.
- Использовать OpenRouter `qwen/qwen3-embedding-8b`, учёт расходов и настраиваемый предел $5 в месяц. При сбое провайдера или достижении предела сохранять доступные виды поиска и показывать неполноту семантики.
- Сохранить существующие чтение, получение оригинальных изображений и форматирование ответов. Метаданные проектов и полей получать по запросу, не раздувая постоянно загружаемые схемы.

## Capabilities

### New Capabilities

- `mantis-search`: источники поиска, фильтры, группировка, ссылки, совместимость чтения и честное представление полноты.
- `mantis-index-lifecycle`: дельта по дате изменения, локальные проекции, доступ, стоимость, восстановление и откат.
- `mantis-guarded-write`: намерение пользователя, инициатор, права, проверка результата, конфликты и продолжение составных операций.

### Modified Capabilities

Нет существующих Mantis specs в `openspec/specs/`; новые требования оформляются тремя capability выше.

## Impact

Реализация затрагивает владельца `vibecoding1c-mcp-host/mantis-ticket-mcp/`, подключение его постоянного состояния в установщике MCP-хоста, зависимости, контракт tools-list proxy и целевые тесты. Code, BookStack и lifecycle 1С сохраняют собственное состояние и управление. Клиенты Windows 10/11/Server 2019+ и терминальные сеансы не получают новых требований к повышению прав.

На 28.09.2026 read-only проверка подтвердила MantisBT 2.28.1, 17 доступных проектов и роль наблюдателя у служебного аккаунта. Перед будущим включением записи ему потребуются минимальные права для согласованных действий. Выборка REST по проекту вернула две страницы по убыванию `updated_at`, включая закрытые обращения; это подтверждение маршрута, а не нагрузочная приёмка. Известные ограничения и источники закреплены в [ADR о сервере](../../../docs/adr/0003-mantis-existing-server-boundary.md) и [ADR о дельте](../../../docs/adr/0005-mantis-modified-date-delta.md).

Согласованные решения grill сохранены в ADR 1–5; ссылки на каждое решение приведены в [дизайне](design.md). Его installed-state checkpoint согласован командой пользователя «приступай к реализации» 28.09.2026. [План проверок](test-plan.md) отделяет локальную реализацию от внешней приёмки.

**Change находится на этапе реализации и локальной проверки.** Подготовлены поиск, отдельное состояние, дельта и управляемая запись; новые возможности выключены по умолчанию. После уточнения пользователя поиск дополнительно ограничен пятью карточками по умолчанию и 12 000 символов на страницу, с продолжением по курсору даже без фильтров. Развёртывание, изменение прав, реальные записи и платная индексация не выполнялись. Linux Docker qualification, тестовый Mantis и canary остаются открытыми задачами. Изменение/обновление самого Mantis, индексирование содержимого файлов, персональная модель ACL и регулярный полный обход базы исключены.
