# Отдельная задача: версии локального vibecoding1c

Пользователь 2026-10-13 выбрал вынести эту работу из `workflow-bound-dependencies`.

Текущий общий checkout обновляется fetch/fast-forward, образы выбираются по tags.
При этом глобальные container names, port keys и state, а также project compose и
индексы не изолированы по версии. Закрепление commit/digests и versioned cache
само по себе не обеспечивает работу двух worktree с разными наборами.

Нужно отдельно согласовать и реализовать:

- immutable distribution commit и image digests из workflow;
- отдельные generations контейнеров, портов, state и хранилищ индексов;
- миграцию существующего runtime с сохранением секретов и чужих данных;
- стоимость повторной индексации и retention используемых generations;
- реальную приёмку двух worktree с разными версиями без взаимного переключения.

До выполнения этой задачи текущая политика локального vibecoding1c сохраняется.
Удалённые MCP остаются в управлении владельцев соответствующих хостов.
