# Решение о пропуске OpenCode, 2026-10-24

После [нативного прогона PM5](g3-pm5-native-clients-2026-10-24.md) пользователь указал: «OpenCode пропускаем». Дальнейшие агентские чтения и повтор reload в OpenCode исключены из текущего квалификационного прогона G3; доступный провайдер для этого прогона больше не требуется. G3-OPENCODE-PROVIDER-QUOTA имеет статус **SKIPPED по решению пользователя**, а не PASS или исправлен.

Исходный результат сохранён: PM5-контекст и подключения после renderer reload подтверждены, агентских вызовов Code/Graph — 0 из-за квоты Big Pickle. Исторические report/JSON/raw evidence не переписываются. Kilo и Cursor сохраняют фактически пройденную область приёмки. OpenCode не блокирует продолжение остальных разрешённых проверок G3.

Решение относится к этому прогону: поддержка OpenCode, общая клиентская матрица и требования к выпуску не удаляются. Для будущего подтверждения агентских чтений OpenCode остаётся прежний сценарий с доступным авторизованным провайдером: два реальных чтения до и два после reload на выбранном тестовом root, с payloads и проверкой сохранности. Полная G3/AC-39 не принимается автоматически. Gate 6, G4, рабочая миграция и публикация этим решением не разрешены и не выполняются.
