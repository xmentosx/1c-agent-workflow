## Метод

Источник — логи Codex `~/.codex/sessions/2026/11/*` с `cwd` в копиях PM5,
события с 2026-11-11 по 2026-11-14 UTC. Субагентский тред считается только с
`subagent_history_start_ordinal`, без пересказа истории родителя. Правка BSL —
`FileChange` или `apply_patch` с путём `*.bsl`. Вызовы памяти — `McpToolCall`
сервера `itl-scoped-cognee`, каждый `id` один раз.

За период 10 пользовательских сессий; правки BSL — в 3 из них, но эти 3 сессии
вели 19 субагентов с собственным контекстом. Поэтому пороги посчитаны в двух
разрезах: по пользовательским сессиям и по тредам агента с правками BSL (у каждого
треда свой старт и свой итоговый ответ). Набрать ~15 пользовательских сессий с
BSL за период не удалось.
